# CS 256 — Data Structures

A collection of Java programming projects completed for CS 256: Data Structures at St. Lawrence University (Fall 2024).

## Overview

This repository contains three programming projects exploring the organization, retrieval, and processing of data using fundamental data structures and algorithms.

The coursework covers arrays, lists, stacks, queues, maps, trees, and introductory algorithm analysis.

## Projects

### 1. Letterman Reboot — Path Finding

A word transformation program that searches for a valid path between two words using stack-based and queue-based traversal.

**Key Concepts:**
- Stack and queue data structures
- Graph traversal and pathfinding
- Word modification operations
- Command-line argument processing

### 2. Star Wars Episode X: A New Heap

A galactic warfare simulation that processes troop deployments and resolves battles using priority queues.

**Key Concepts:**
- Heaps and priority queues
- Priority-based event processing
- Median tracking using two heaps
- Object-oriented programming

### 3. SLU-QL — Relational Database Engine

A simplified relational database engine supporting table operations, conditional queries, indexing, and joins.

**Key Concepts:**
- Hash-based and tree-based indexing
- Relational data management
- Query processing and table joins
- Data abstraction and polymorphism
